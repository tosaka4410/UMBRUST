# v0.2 — 戦闘の使い分けとボス固有行動

v0.1の周回・探索・6本の付与・保存形式を引き継ぎ、戦闘を拡張した。以下の数値はプレイテスト前提の仮設定。v0.1実装メモの戦闘に関する記述と異なる部分は本書を優先する。

## 武器

| 武器 | 攻撃 | 新しい特徴 | 体勢への基本ダメージ |
| --- | --- | --- | --- |
| 剣 | 振り下ろし→切り返し→強い薙ぎ払い | 三段目は威力1.45倍、リーチ103、全体0.46秒 | 18 / 18 / 38 |
| 槍 | 細長い直線の突き | リーチ156。敵の中心がリーチの70%以上先なら威力1.2倍 | 24 |
| 斧 | 重い薙ぎ払い | 上下にも広い判定。盾の軽減を無視 | 65 |

攻撃中の移動80%、別の攻撃による割り込み禁止、回避によるキャンセルは継続。攻撃終了直前0.14秒だけ次のA/B入力を一つ予約でき、現在の攻撃終了後に開始する。回避・回復・固有ステップ・部屋移動・管理画面を開く操作で予約を解除する。

剣は同じ攻撃スロットで、前の攻撃開始から「全体動作時間＋0.45秒」以内に次を始めると連撃が進む。三段目の次は一段目。攻撃時に向きを固定し、移動入力で攻撃判定が途中反転しない。

## 盾と体勢

盾持ちは接近中・予兆中の正面の軽い攻撃を65%軽減し、体勢へのダメージも30%に軽減する。背後、攻撃後の硬直、崩し値60以上の攻撃は防御できない。

体勢ゲージの上限は錆走り30、盾持ち60、燻り火25、鐘守95、坑夫110、強ボス150、夜ボス175。満ちると現在の動作を中断し、1.25秒のBREAK。BREAK中の被ダメージは1.2倍、追加の体勢蓄積はしない。被弾から2秒後に毎秒12ずつ体勢ダメージが回復する。

## 敵・ボス

| 敵 | 行動の使い分け |
| --- | --- |
| 錆走り | 方向を固定した予兆から突進。背後へ回避、またはジャンプ |
| 黒殻の番人 | 正面を盾で守り、遅い薙ぎ払い。斧か背後が有効 |
| 燻り火 | 近づく相手から距離を取り、狙い線の後に射撃。部屋端では射撃に切り替える |
| 鐘守 | 突進→両側へ地面を走る衝撃波→薙ぎ払い |
| 埋葬坑夫 | 地砕き→狙った位置の左右へ黒岩噴出→薙ぎ払い |
| 鐘を喰らうもの | 薙ぎ払い・扇状射撃・突進。第二形態で衝撃波と黒岩を追加 |
| 黒錆の王 | 薙ぎ払い・衝撃波・扇状射撃。第二形態は突進・黒岩・衝撃波・射撃・地砕き |

強ボスと夜ボスはHP50%以下で一度だけ、1.25秒の移行演出を挟む。第二形態は接近速度1.18倍、攻撃後の硬直0.8倍。技の予兆時間は短縮しない。

衝撃波は低い判定（38px）、地砕きは44pxで、基本ジャンプで回避できる。黒岩は高さ170px・半幅46px。発生位置を固定し、少なくとも0.65秒の独立した予告を出す。第二形態は三か所へ時間差で発生する。

近接攻撃・範囲攻撃は、一つの攻撃につきプレイヤーに一回だけ接触する。回避無敵中に接触した場合も消費済みとする。移動する衝撃波・弾は前フレームからの移動区間で判定し、低フレームレート時にすり抜けにくくした。範囲攻撃は術者撃破・部屋移動・周回終了で消える。

## 打撃演出・表示

- ダメージ数値、穂先補正`TIP`、盾防御`GUARD`、体勢崩し`BREAK`を表示。
- 武器ごとの攻撃軌跡、命中火花、短い停止演出、軽い画面揺れ。
- 停止演出は本人・対象の動作に限る。探索時計、侵食、他の敵は進み続ける。回避で停止演出から抜けられる。
- ボスHPの下に体勢ゲージ、攻撃名、避け方の短い案内を表示。
- 設定に画面揺れの切り替えを追加。以前のセーブはそのまま読み込み可能。

## 検証

既存の回帰検証に41チェックを追加。三連撃、予約入力の排他・解除、盾の方向、斧の崩し、BREAK補正、槍先端補正と上下判定、時計の進行、近接・範囲攻撃の予兆と一回性、ジャンプ・回避での回避、移動区間の判定、第二形態の一回性とパターン、危険範囲の後始末、画面揺れ設定の保存を確認する。

実描画の確認は既存9画面に黒岩の予告・斧によるBREAKを加えた11画面。自動検証は入力や戦闘ルールを確認するもので、実際の難易度・爽快感を保証するものではない。実パッドによる操作感と一周を通した難易度は引き続きプレイテストで調整する。
