# UMBRUST v0.1 実装メモ

これは初版の記録です。現在の戦闘拡張は [v0.2戦闘メモ](combat-v0.2.md) を参照してください。

ユーザー提示の「UMBRUST プロトタイプ仕様 v0.1」の最初の試作範囲を実装したものです。【仮】項目は以下の値を採用し、ここに記載のない最終的なバランス調整はプレイテストに委ねます。

## 周回・侵食

- 通常の時計：240秒で予告、300秒で最外部屋が侵食、420秒で夜。短縮テストは時計のみ6倍速。
- 接続の深さ：炉跡を0、最外部屋を4とする。深さ4/3/2/1の侵食開始は300/330/360/390秒。左右座標には依存しない。
- 炉跡は常に安全。侵食済みの部屋は通行可能で、実時間1秒につき最大HPの3%のダメージ。回避無敵でも防げない。
- 夜は自動転送しない。夜に炉跡へ入る、または炉跡で夜を迎えると、HPと回復回数を補充して夜ボスを召喚。戦闘中は炉跡の出口・休憩を使えない。
- 敵、宝箱、取得済みの回復増加、地面に置いた武器、破壊した壁は周回終了まで状態を保持する。

## 戦闘・回復

| 項目 | 値 |
| --- | --- |
| 基本HP | 100（固定初期付与で実際の開始時は106） |
| 移動速度 | 320 px/s、加速度2600 px/s² |
| ジャンプ初速 / 重力 | 710 px/s / 1700 px/s² |
| 回避 | 0.22秒、無敵0.20秒、再使用0.65秒 |
| 疾走者のステップ | 0.13秒、再使用2.5秒、無敵なし |
| 剣 | 基礎威力22 / リーチ88 / 攻撃全体0.36秒 |
| 槍 | 基礎威力28 / リーチ146 / 攻撃全体0.52秒 |
| 斧 | 基礎威力42 / リーチ104 / 攻撃全体0.72秒 |
| 通常攻撃中の移動 | 通常速度の80%、完全には停止しない |
| 回復 | 0.8秒、最大HPの40%、開始時に回数を消費 |
| 回復回数 | 初期3、上限増加2か所、最大5 |

同時に二つの通常攻撃は出せない。回避で攻撃をキャンセルできる。回復中は攻撃・回避・ジャンプ・固有ステップ不可。被弾では回復動作を中断しない。赤い地面の範囲と頭上の光が予兆で、攻撃後に硬直する。

## 武器と付与

- 所持上限6、攻撃用2。6本すべての付与が有効。全武器2枠、同一武器内重複なし、移動付与は最大1枠。
- 現行UIは横3列×縦2段。左上が武器A、左下が武器B。矢印キー＋Enterで枠の入れ替えができ、空き枠も位置を保持する。武器管理中はA/D・左スティックで左右移動できる。WASDによるメニュー操作は廃止。
- 各枠で傾向候補60%・その他40%を抽選。既存の枠と衝突する候補を除外し、選んだ候補群が空なら合法な全候補から再抽選。
- コモン/アンコモン/レアの威力倍率は1.0/1.25/1.5。ステータス付与値は6%/9.5%/13%。移動能力の性能は同じ。
- 武器による加算上限：攻撃60%、最大HP50%、速度35%。永続補正は別加算で各最大5%。
- 二段ジャンプ・壁破壊は同じ能力を複数持っても強化されない。
- 雑魚10%コモン、宝箱80%コモン、中ボス100%アンコモン、強ボス100%レア。夜ボスは武器なし。
- 交換時に武器威力差、付与合計の変化、失う移動能力を表示。捨てた武器は再取得可能。最後の1本は捨てられない。

## マップ

| 拠点 | 部屋 | 役割 |
| --- | --- | --- |
| 炉跡 | 帰還の炉 / 灰の街道 | 出発・決戦、休憩、初期宝箱 |
| 鐘楼 | 風の回廊 / 鐘守の間 / 頂の祭壇 / 風渡りの書庫 | 基本ジャンプで階段状の足場を登る、中ボス、任意の強ボス、二段ジャンプの寄り道 |
| 廃坑 | 砕けた坑道 / 掘削跡 / 鉱脈の底 / 黒岩の宝物庫 | 分岐、中ボス、壁破壊の寄り道 |

部屋は別々の `.tscn` で、共通の描画・地形構築スクリプトを使用する。部屋インスタンスを周回中は保持し、非表示の部屋は物理・処理を無効にする。ゲーム画面の出口はEで使用する。

必須の接続はスキルゲートなし。高所の寄り道の帰路は地上出口。黒岩は開通状態を保持する。起動時とテストで接続グラフの必須ルート到達性・ボーナス部屋の帰路を検証する。ランダム生成と任意形状の地形の自動到達性検証は未実装。

仕様の拠点傾向の例には空中攻撃・防御・回復関連もあるが、試作の「ステータス3種」に合わせ、鐘楼は二段ジャンプ・速度・攻撃、廃坑は壁破壊・HP、炉跡は攻撃・HPに寄せた。地図にもその内容を表示する。

## 永続報酬

- 武器なし宝箱：8欠片。寄り道の欠片：12。中ボス：15。強ボス：25。夜ボス：50。クリア追加：30。
- 槍・斧の初期武器解放：各20欠片。初期武器はコモン、固定付与は攻撃+6%・最大HP+6%。
- 攻撃・HP・速度を各1%ずつ5段階強化。費用は15/25/35/45/55欠片。3種類から最大3つをセット。
- 敗北・メニューからの周回終了でも獲得通貨を保存。次の周回では武器・回復上限・敵・地形の状態をリセット。

## 将来の拡張と制限

プレイヤーノードごとに専用の入力アクション名前空間（`PlayerControls`）、所持品、戦闘状態、Camera2Dを持つ。デバイスID・キーボード使用可否もプレイヤー単位で設定できる。現在の周回管理・UIはソロ前提。ネットワーク同期、仲間への譲渡、集合判定、蘇生、他キャラクターは未実装。

表示は1440×900を基準にウィンドウへ拡縮。日本語フォントはOSのHiragino/Noto CJK/Yu Gothicから取得するため、Linux等では日本語フォントのインストールが必要な場合がある。効果音は合成した簡易音、BGMなし。配布用のエクスポート設定はまだ作成していない。

## 検証

`tests/regression.gd` は固定シードで2700本の抽選を検証し、さらに実際のシーン・物理フレームを使って移動、ジャンプ、攻撃の排他、回避、回復、交換、落とした武器、スキルゲートの帰路、敵の非復活、レアリティ保証、侵食、夜の手動帰還、補充、勝敗報酬、セーブ、リセット、入力保存、永続上限を確認する。

`scenes/visual_check.tscn` は準備・ゲーム・6本所持の比較・地図・設定・鐘楼・侵食・夜ボス・結果の9画面をGodotのレンダラーで描画し、`/private/tmp/umbrust-*.png` に出力する。テストファイルは通常のプロフィールを変更しない。実パッド、他OS、長時間のバランス確認は今後のプレイテスト項目。
