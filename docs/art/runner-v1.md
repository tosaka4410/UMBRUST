# 疾走者 — アート v1

## デザイン

黒錆の土地を走る、軽装の探索者。象牙色の面頬付き兜、煤けた青緑の外套、灯火色の長いスカーフ、革の帯と回復瓶を共通意匠とする。顔は覆い、細い琥珀色のバイザーで視線を表現する。

イメージイラストとゲーム用素材は同じ外観を共有する。ゲーム用は小さな表示でも輪郭が読み取れるよう、材質の細部より明暗と大きな形を優先する。

生成方法：組み込みの image_gen ツール。元の生成画像の透過・色を保持し、Godot側でアトラス領域を指定して使用する。

## アニメーション

| 状態 | コマ番号（0始まり） | 動作 |
| --- | --- | --- |
| 待機 | 0–3 | 5fpsループ |
| 走行 | 4–7 | 11fpsループ |
| ジャンプ上昇 / 落下 | 8 / 9 | 上下速度に応じて選択 |
| 回避・固有ステップ | 10 | 低い姿勢と残像 |
| 被弾 | 11 | 被弾フラッシュ付き |
| 攻撃 | 12–14 | 武器の動作時間に同期 |
| 回復 | 15 | 瓶を口元へ運ぶ姿勢 |

スプライトは右向きで、左向きはGodot側で反転する。武器は独立したレイヤーとして手の位置から描画し、剣・槍・斧の装備に合わせて切り替える。各コマを元解像度の20%で描画し、立ち姿の高さは約60px。

生成アトラスは厳密な均等グリッドではないため、`hframes=4 / vframes=4` だけで分割しないこと。`RunnerVisual.REGIONS` を使用する。足元は `PIVOTS`、握る位置は `HANDS`、武器の領域と握り位置は `WEAPON_REGIONS` / `WEAPON_GRIPS` に定義した。PNG自体には切り抜き・色補正・拡大縮小などの加工をしていない。

## ゲームへの適用

`Runner` の子ノード `RunnerArt` が見た目を担当する。移動・戦闘・侵食・当たり判定は既存のまま。剣の斬撃軌跡、回復リングなどの効果は引き続きコードで描く。準備画面の肖像は `concept.png` の一部をAtlasTextureで参照する。

通常はF5でゲームを実行。素材だけを見る場合は `scenes/art_preview.tscn` を開いてF6で実行する。

## 検証と調整余地

透過チャンネル、全16コマが画像内に収まること、コマの重複がないこと、回復・回避・被弾への切り替えを自動検証。ゲーム画面・準備画面・戦闘・素材プレビューを実際のGodotレンダラーで確認した。

これはゲームに組み込める初版アート。走行4コマ、攻撃3コマの限定アニメーションで、手描きで中割りした滑らかな最終版ではない。剣・槍・斧は共通の身体ポーズに別レイヤーの武器を組み合わせている。必要に応じて次版で武器専用ポーズや走行中割りを追加できる。
